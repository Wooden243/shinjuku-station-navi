# 人手補正

公開原本は変更せず、確認済みの名称・分類・接続補正をここに記録します。

- `place_overrides.csv`: 改札・出口の名称、事業者、方面、設備、利用時間、
  注意情報、階層、座標、接続ノードの補正
- `platform_gate_mapping_template.csv`: 将来のホームから改札への案内用テンプレート

補正行には `evidence_url` と `note` が必須です。現地確認済みとする場合は
`verified_on_site=true` と `verified_at` も記録してください。
複数の設備・注意情報は `|` で区切ります。公開原本にない値を根拠なしで
追加せず、未確認欄は空欄のままにしてください。
