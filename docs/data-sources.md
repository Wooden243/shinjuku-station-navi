# データ出典

主データは東京都都市整備局「新宿駅周辺の施設情報等」です。配布ページは <https://catalog.data.metro.tokyo.lg.jp/dataset/t000008d0000000037>、ライセンスはCC BY 4.0、公開日は2023-02-28です。

原本 `data/raw/shisetsu_root.zip`、仕様書、取得時刻、SHA-256は `data/raw/manifest.json`、加工ファイル別SHA-256、件数、座標系、警告、変換内容は `data/processed/manifest.json` に記録します。API境界はEPSG:4326、距離はメートルです。

現在の加工件数はノード2,506、リンク2,647、改札31、出口35、施設1,188です。施設は原本のentity/geometryを分類したもので、架空店舗ではありません。未知階層は推測しません。出口周辺施設は60m以内の公開データを直線距離で導出し、道路・方面とは扱いません。

国土交通省「歩行空間ネットワークデータ等整備仕様」と「ほこナビDP」は関連する政策・仕様の参照先ですが、この東京都配布ZIPの提供者を国土交通省とは表示しません。手動補正は `data/overrides` に根拠付きで記録します。
