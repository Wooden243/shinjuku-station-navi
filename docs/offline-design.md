# オフライン設計

Service Workerはアプリシェルと取得済みGET応答をキャッシュします。経路計算に必要なノード、方向付きリンク、地点、施設、階層図、版情報は `/api/offline-bundle` から取得しIndexedDBへ保存します。IndexedDB不可時は、そのタブ内のメモリへ退避し警告します。

ブラウザDijkstraはAPIと同じ方向付き辺、メートル単位距離、毎分80m、階段回避条件を使用します。到達不能なら経路を作りません。地図矢印はオンライン・オフライン共通の `route_by_floor` と座標順を使います。

投稿は `client_submission_id` 付きで端末キューへ保存し、`online` イベントで冪等送信します。初回オンライン保存前は利用不可と明示します。版と公開データ更新日を表示し、古いデータを警告します。Service Workerや保存失敗だけで画面全体を停止させません。
