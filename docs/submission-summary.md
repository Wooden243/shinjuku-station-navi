# 提出用概要

## 課題

新宿駅周辺は鉄道事業者、地下通路、階層、出口が複雑であり、初めて
訪れる人が「改札から目的の出口まで」を把握しにくい。

## 解決策

改札と出口を選択すると、公開された歩行空間ネットワークから経路を
計算し、階層別2D地図と文章で示すWebアプリを提供する。GPSを前提と
せず、通信環境や屋内測位精度に依存しない案内を目指す。

## オープンデータの利用

東京都都市整備局「新宿駅周辺の施設情報等」の歩行空間ネットワークを、
ノード・リンク・階層・移動制約を保持したまま正規化して使用する。
公開原本、変換結果、人手補正を分離し、取得日時とハッシュ値を記録する。

## 技術

- FastAPI / Pydantic / NetworkX / PyProj
- Next.js / React / TypeScript / MapLibre GL JS
- GeoJSON
- pytest / ESLint / TypeScript

## 検証方針

公開データの更新時点との差異があり得るため、改札・出口の名称と位置、
通路接続、階層移動を現地調査で確認する。未確認情報は画面とデータで
明示し、到達不能時に疑似経路を生成しない。
